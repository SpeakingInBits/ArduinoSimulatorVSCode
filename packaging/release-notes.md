## Install

1. Download [metro-simulator-{{VERSION}}.vsix](https://github.com/SpeakingInBits/ArduinoSimulatorVSCode/releases/download/v{{VERSION}}/metro-simulator-{{VERSION}}.vsix).
2. In VS Code 1.100 or later, open the Extensions view, select **...** at the top, and choose **Install from VSIX...**.
3. Pick the file you downloaded.

To try it, open the Command Palette and run **Metro Simulator: New Project from Example**.

Found a problem? [Open an issue](https://github.com/SpeakingInBits/ArduinoSimulatorVSCode/issues) and say what you did and what you expected.
