# Arduino Simulator for VS Code

A planned VS Code extension that lets students write and test CircuitPython for the Adafruit
Metro M0 Express without a physical board, including simulated circuits and kit parts. Arduino
C++ support for the Metro 328 is planned as a second step.

The project is at the feasibility stage. The [spike](spike/README.md) shows real CircuitPython
running in VS Code through WebAssembly, and it is proof code rather than a usable product.
